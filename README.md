# MSCS-633-M50-Assignment2

## Project Overview

This project is a simple Python-based QR Code Generator application. It allows users to input a URL and generates a corresponding Quick Response (QR) code, which can be scanned using any QR code scanner or mobile device.

QR Codes were invented in 1994 by the Japanese company Denso Wave and are widely used today for fast and efficient information sharing.

### Technologies Used

Python 3

qrcode library

Pillow (PIL) for image processing

Visual Studio Code

GitHub for version control


### Manifest File

The requirements.txt file serves as the manifest file for this project.
It lists all the Python dependencies required to successfully run the application.

### Installation & Setup
Step 1: Install Python

Ensure Python 3 is installed:

python --version

Step 2: Install Dependencies

Install required libraries using the manifest file:

pip install -r requirements.txt

### How to Run the Application

Run the Python script using the command below:

python qr_generator.py


When prompted, enter a valid URL (example):

https://www.google.com/

### Output

A QR code image will be generated and displayed

The image will be saved locally.


You can scan the QR code using any smartphone QR scanner.

### Features

Accepts any valid URL as input

Generates a high-quality QR code

Saves QR code as an image file

Simple and easy-to-use command-line interface
